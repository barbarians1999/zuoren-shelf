# 左人书架

左人书架是一个静态在线阅读网站。

- 在线阅读：[左人书架 GitHub 版](https://barbarians1999.github.io/zuoren-shelf/)
- 友情链接：[社科书架 GitHub 版](https://barbarians1999.github.io/sheke-shelf/)

网站文件位于仓库根目录，可直接作为静态网站发布。

搜索入口由 `scripts/generate_search_pages.py` 根据书目和正文生成。更新书目或章节内容后，按[搜索收录入口维护说明](docs/search-visibility.md)重新生成页面与 `sitemap.xml`。
